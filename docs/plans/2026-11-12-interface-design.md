# v1.5 原生浮窗与多语言

采用 196 × 104 的深色圆角浮窗，顶部拖动区，中部图标和“一键拔线”，底部状态。保留游戏前台显示和位置记忆。相比仅放大旧图标，明确文字更容易理解；相比完整控制面板，浮窗更少遮挡。

菜单提供跟随系统、简体中文、繁體中文、English，即时刷新并保存偏好。所有状态、提示和操作使用同一翻译入口，繁体通过 Foundation 转换。

请求处理中禁用重复操作；超时清理匹配 UUID 的请求，十秒以上遗留请求允许重试。反馈显示五秒，并提供完整提示文本。保留日志入口。

验证：完整构建、Swift 类型检查、源码差异检查和真实桌面预览。对局断线效果仍需游戏内验证。
